# Ali Asset Card

A premium local-first productivity app for Ali Asset Card users. It includes a secure, polished to-do experience with persistent browser storage and card-like dashboard styling.

## Features

- Add, edit, complete, and delete card-related tasks
- Local browser storage persistence with no backend required
- Search and filter by status, priority, and category
- Dark mode and light mode toggle
- Priority tracking with due dates and categories
- Export/import tasks as JSON
- Mobile-first responsive interface

## Run locally

```bash
git clone https://github.com/lulkoangpuok26-cloud/todo-list-app.git
cd todo-list-app
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```
